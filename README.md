# Security Assessment Intelligence Platform

An explainable, evidence-driven VAPT/WAPT platform that connects technical findings to risk, compliance, remediation, and verified retesting.

## Disclaimer
**This is an authorized security assessment platform.**
It must never be used to scan arbitrary targets without authorization. The platform requires defined scopes and authorization controls.

## Project Structure
- `/frontend`: React + Vite + TypeScript web interface
- `/backend`: FastAPI Python API
- `/worker`: Background tasks (planned)
- `/docs`: Project documentation
- `/demo-lab`: Intentionally vulnerable training lab (planned)
